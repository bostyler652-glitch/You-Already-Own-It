# Buy / Wait / Don't Buy

A launch-ready MVP for a $3/month purchase-decision subscription.

## Run
Install Node.js 18+.
npm install
npm run dev
Open http://localhost:3000

## Included
- Purchase analyzer
- BUY / WAIT / DON'T BUY verdict
- 0–100 purchase score
- Cost-per-use calculation
- Saved decision history in browser
- Responsive landing page
- $3/month Pro CTA

## Production connections
For real customers, connect:
- Supabase: accounts + cloud database
- Stripe: $3/month recurring subscription
- Vercel: hosting/deployment
- Email provider/cron: optional reminders

The app does not make fake payment claims or require API keys in the starter.
